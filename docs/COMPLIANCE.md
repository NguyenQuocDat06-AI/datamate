# Compliance with the challenge rules

| Rule | How the solution meets it | Evidence |
|---|---|---|
| Total parameters of all models ≤ 15 B | One model, `google/gemma-4-12B-it`: 11,959,730,224 parameters. No second model, embedding model, reranker, adapter or teacher at inference | `docker/image/model_manifest.json` |
| Model released before 2026-10-01 | Released 2026-06-03 | model card, manifest |
| Open license | Apache-2.0 | manifest |
| Offline inference | `HF_HUB_OFFLINE=1`, weights in the image, no network access in the pipeline | `docker/image/predict.sh`, `Dockerfile` |
| Hardware / time | NF4 or fp16 chosen by a real GPU pre-flight; T4 does not use bf16; time budget enforced by `run_submission.py` | `container/gpu_preflight.py` |
| No hard-coded answers or IDs | No shop/question IDs or dataset literals in source; values are matched against the shop's data at run time | `tests/test_no_dataset_literals.py` plus manual review |
| No test data for training | No parameter training at all. Few-shot examples come from the training split only, excluding the current shop and question | `docker/training_code/README.md` |
| No public/private gold in the artifact | Not packaged; gold files and `submission.jsonl` of the public set are git-ignored | `docker/tools/make_manifest.py` records `no_public_private_gold` |
| Logs | Per-question log in `/result/logs/questions.jsonl` (id, answer, elapsed time, generated thinking) | `docker/overlay/submission_audit.py` |
| Reproducibility | Pinned dependencies, pinned model revision, fixed seed, greedy decoding | `docker/requirements.txt` |

## Open risks and limits

* **Provenance of few-shot labels.** The structured intents in the frozen few-shot bank were produced by a hosted model
  during development; the raw provider responses and historical prompts were not retained. We do not claim to
  reproduce them. The final labels, checksums, export code and prompt templates are packaged. The organizers must accept
  this or the bank must be regenerated by the submitted model.
* **Hosted development model.** Development measurements used hosted/Kaggle-served Gemma 4 12B, not the container.
  Packaged-image behavior on full data is not yet measured.
* **Untested hardware.** The image has not been run on Blackwell-class GPUs; the pre-flight falls back from NF4 to
  fp16, but this path was not exercised there.
* **Accuracy.** Public numbers are optimistic (see [`EVALUATION.md`](EVALUATION.md)); no private-set claim is made.
* **Data hygiene.** Real customer data from public shops must never appear in tests, docs or commits.
